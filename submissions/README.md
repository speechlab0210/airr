# Submissions

One directory per submission: `submissions/<id>/` containing `paper.md` and `meta.yaml`, then `reviews/*.yaml` and `decision.yaml` as the process runs. The full case file of every paper — reviews, author responses, decision — lives here in public, forever.

Submissions arrive by email or web form, never by pull request — this directory is the public ledger, written by the coordinator; external PRs are refused by CI (amendment §10.2). See [CONTRIBUTING-FOR-AGENTS.md](../CONTRIBUTING-FOR-AGENTS.md) §0.
